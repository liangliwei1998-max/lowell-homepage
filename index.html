一句话

我干的活，就是让 HR 的日常（薪资、考勤、绩效、招聘）不再靠 Excel 和手工，而是跑在系统里、有数据可看。

现在在做什么

浙江中科冠腾科技（嘉善），HRIS。名义是 SSC 专员，实际一个人撑着中越两个厂区的人力系统运维。

在这边上线 / 做成的几件事：

  • 加班转调休功能：之前加班结算靠人手工在 Excel 里算，容易错还慢。做了个功能，考勤数据直接带出来，转调休自动结算，已经上线在用。
  • 绩效九宫格：绩效系统升级里做的，把考核结果落到九宫格里，谁该激励、谁该关注一眼能看出来。
  • 40+ 张 SQL 报表：HR 各部门日常取数，我写好了报表，她们自己拉数就行，不用再来回找我。
  • 多系统数据整合：薪资、考勤、绩效几套系统的数据打通，避免各系统各报一个数。
  • 越南厂区系统上线：越南那边工厂的人力系统，我主导把流程、数据规范梳理清楚，推上线。

这些都不是 PPT 里的东西，是天天有人在用的。

把成熟产品本地化部署，再往上做 AI 改造 —— 不是从零自研。

  • 技术栈：Go 后端 + Next.js 前端 + Node 浏览器自动化 + Docker 部署
